# Licensing YOUR code — options

Your application code (`app/main.js`, `app/preload.js`, `app/db.js`,
`app/schema.sql`, `app/src/index.html`, etc.) is yours. You do **not** have to
pick any license — without one, you keep all rights and nobody may legally
redistribute your code.

Pick a path:

## Option A — Keep it closed (default; no action needed)

Do nothing. The code is "All Rights Reserved". You can sell it, license it to
specific people, or keep it private. This is the current state of the project.

## Option B — Release as open source (MIT)

If you want others to freely use/modify/redistribute (still allows commercial
use), copy the text below into `app/LICENSE` and fill in the year + name.
MIT is what all of this project's dependencies use, so it keeps everything
consistent.

```
MIT License

of this software and associated documentation files (the "Software"), to deal
in the Software without restriction, including without limitation the rights
to use, copy, modify, merge, publish, distribute, sublicense, and/or sell
copies of the Software, and to permit persons to whom the Software is
furnished to do so, subject to the following conditions:

The above copyright notice and this permission notice shall be included in all
copies or substantial portions of the Software.
```

## Option C — Other common choices

| Goal | License |
|---|---|
| Open source, but derivatives must also be open | GPL-3.0 |
| Open source, permissive, patent grant explicit | Apache-2.0 |
| Free for churches/non-profits only | Custom written agreement (no standard license does this cleanly) |

Compare licenses at https://choosealicense.com

## Practical tips

- You can change your mind later for code YOU wrote, but not for code you
  already accepted from outside contributors under a specific license.
- If volunteers contribute code, state the project's license in writing first
  so ownership stays clear.
- Whichever option you choose, keep `THIRD-PARTY-NOTICES.md` with any
  distribution — that obligation exists regardless of how you license your own
  part.
